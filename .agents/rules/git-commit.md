# Git & Commit Policy

Guidelines and constraints for version control operations across AI Hedge.

---

## 1. No Automatic Commits
- **Explicit Approval Required**: Never run `git commit`, `git push`, or automatically create commits without explicit confirmation and approval from the user.
- **Proactive Proposal**: When changes are complete and verified, present a summary of the modified files and propose a clear commit message, but wait for user approval before executing any git commit or push commands.
- **Diff Transparency**: Keep changes clean and allow the user to review the working tree state (`git status`, `git diff`) before committing.
